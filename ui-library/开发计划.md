# UI 组件库与设计系统 · 开发计划

> 原则：**每个阶段都产出可运行、可验证的东西**，先小步跑通再逐步加深。

## 阶段一 · 基础组件

- **目标**：能复用
- **产出**：3-5 个基础组件

- [ ] 按钮 / 输入
- [ ] 弹窗
- [ ] 统一样式

## 阶段二 · 主题化

- **目标**：可换肤
- **产出**：令牌化主题

- [ ] 抽设计令牌
- [ ] 明暗主题
- [ ] 品牌色

## 阶段三 · 文档化

- **目标**：可协作
- **产出**：Storybook 文档站

- [ ] 示例与属性表
- [ ] 在线调试
- [ ] 使用指南

## 阶段四 · 发布

- **目标**：可分发
- **产出**：发布的组件包

- [ ] 视觉回归测试
- [ ] 无障碍检查
- [ ] 版本化发布

---

### 里程碑与验收

| 阶段 | 验收标准 |
|---|---|
| 阶段一 · 基础组件 | 3-5 个基础组件 |
| 阶段二 · 主题化 | 令牌化主题 |
| 阶段三 · 文档化 | Storybook 文档站 |
| 阶段四 · 发布 | 发布的组件包 |

> 建议：每完成一个阶段就在本目录下建一个具体项目子目录，把成果固化下来。
