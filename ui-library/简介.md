# UI 组件库与设计系统 · 简介

> 打造可复用的组件库与设计系统

## 能做什么

- 组件封装与 API 设计
- 主题与暗色模式
- 无障碍（a11y）
- 文档与示例站
- 可视化调试与回归

## 适合的项目

- **团队组件库**：多项目共用
- **产品设计系统**：统一视觉与交互
- **开源组件包**：对外发布

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：Node 22/24、Radix UI / shadcn、Storybook、Tailwind
- 注意：可从「复制即用」的 shadcn 模式起步，再抽象成自有组件库

## 快速开始

```bash
npx shadcn@latest init
npx storybook@latest init
npm run storybook
```
