# UI 组件库与设计系统 · 可实现的典型功能

> 以下为该子方向可落地的功能清单，可作为选题与需求池。

## 基础组件

- **按钮 / 输入**：多状态与尺寸
- **弹窗 / 抽屉**：无障碍焦点管理
- **反馈**：Toast / 加载 / 骨架

## 主题

- **明暗主题**：一键切换
- **令牌化**：颜色 / 间距统一
- **品牌定制**：换色即换肤

## 文档

- **示例与用法**：复制即用
- **属性表**：API 说明
- **在线调试**：实时改属性

## 质量

- **视觉回归**：截图对比
- **无障碍检查**：自动扫描
- **版本发布**：语义化版本

---

> 每个功能都可独立成一个小项目，建议按「最小可用 → 好用 → 自动化」的顺序推进。
