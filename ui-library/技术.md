# UI 组件库与设计系统 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 无头组件 | Radix UI / Headless UI | 只管逻辑与无障碍 |
| 样式 | Tailwind + CSS 变量 | 主题令牌驱动 |
| 文档 | Storybook | 组件工作台 |
| 质量 | Chromatic / Vitest | 视觉与单测 |
| 发布 | npm / GitHub Packages | 版本化分发 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **设计令牌**：颜色、间距、字号的统一定义
- **无头组件**：逻辑与样式分离
- **无障碍**：键盘、焦点、ARIA
- **组合优于继承**：用组合 API 提升灵活性

## 学习路径

1. 先做几个基础组件（按钮 / 输入 / 弹窗）
2. 再抽主题与令牌
3. 最后补齐文档与测试
