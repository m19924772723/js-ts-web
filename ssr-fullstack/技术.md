# SSR 全栈应用 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 框架 | Next.js 15 / Nuxt 3 | 全栈一体、生态成熟 |
| 渲染 | SSR / SSG / ISR | 按需选择渲染模式 |
| 数据 | Prisma / Drizzle | 类型安全的 ORM |
| 鉴权 | NextAuth | 开箱即用的登录 |
| 内容 | Markdown / MDX | 写作即内容 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **渲染模式**：SSR、SSG、ISR 的取舍与适用场景
- **数据获取**：服务端取数与客户端取数的边界
- **API 路由**：在前端项目里写后端接口
- **SEO**：元信息、站点地图、结构化数据

## 学习路径

1. 理解 SSR / SSG / CSR 的差异
2. 掌握一个全栈框架的路由与数据约定
3. 做一个带后台的内容站并部署
