# SSR 全栈应用 · 简介

> 用 Next.js / Nuxt / Astro 做服务端渲染与全栈一体化

## 能做什么

- 服务端渲染与静态生成
- API 路由与全栈 CRUD
- SEO 优化与分享卡片
- 内容驱动站点（Markdown / CMS）
- 一体化部署

## 适合的项目

- **博客 / 内容站**：SEO 友好、加载快
- **营销落地页**：首屏体验好
- **CMS 前台**：内容 + 后台一体

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：Node 22/24、Next.js 15 / Nuxt 3 / Astro 5、Prisma、npm
- 注意：既出页面也出 API，适合内容站与全栈小应用

## 快速开始

```bash
npx create-next-app@latest my-app
cd my-app && npm install
npm run dev   # http://localhost:3000
```
