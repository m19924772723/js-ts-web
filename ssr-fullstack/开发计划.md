# SSR 全栈应用 · 开发计划

> 原则：**每个阶段都产出可运行、可验证的东西**，先小步跑通再逐步加深。

## 阶段一 · 起站

- **目标**：跑通框架
- **产出**：一个可部署的站点

- [ ] 初始化项目
- [ ] 配置路由与页面
- [ ] 本地构建通过

## 阶段二 · 内容化

- **目标**：内容驱动
- **产出**：Markdown 博客

- [ ] 接入 Markdown
- [ ] 列表与详情页
- [ ] 标签与分页

## 阶段三 · 全栈化

- **目标**：有后端能力
- **产出**：带评论 / 后台的站点

- [ ] 接数据库
- [ ] API 路由
- [ ] 简单后台

## 阶段四 · 优化上线

- **目标**：可交付
- **产出**：上线的内容站

- [ ] SEO 与站点地图
- [ ] 图片与性能优化
- [ ] 部署与域名

---

### 里程碑与验收

| 阶段 | 验收标准 |
|---|---|
| 阶段一 · 起站 | 一个可部署的站点 |
| 阶段二 · 内容化 | Markdown 博客 |
| 阶段三 · 全栈化 | 带评论 / 后台的站点 |
| 阶段四 · 优化上线 | 上线的内容站 |

> 建议：每完成一个阶段就在本目录下建一个具体项目子目录，把成果固化下来。
