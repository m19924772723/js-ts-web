# JavaScript / TypeScript — Web 前端与 Node 后端

**定位**：网页、单页应用、Node 接口服务、CLI 工具、浏览器自动化

**本机状态**：✅ 可直接开发

**工具链**：Node v22.22.2（托管·PATH）/ v24.19.0（系统）；npm 10.9.7；pnpm

**建议技术栈**：原生 JS/TS、Vite、React / Vue、Express / Fastify、Playwright

**注意**：无全局 tsc，需 `npm i -D typescript` 本地安装；npm 全局包为空
