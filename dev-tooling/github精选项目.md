# 前端工程化与 CLI · GitHub 精选项目

> 以下为该方向值得参考的开源项目，星标为 2026-10 前后近似值，请以仓库当前页面为准。
> 「可借鉴」一栏说明读源码或使用时最值得学习的地方。

| 项目 | 星标 | 亮点 | 可借鉴 |
|---|---|---|---|
| [vitejs/vite](https://github.com/vitejs/vite) | 83k | 极快构建工具 | 插件体系与 HMR |
| [evanw/esbuild](https://github.com/evanw/esbuild) | 39k | 极速打包器 | 高性能实现思路 |
| [vercel/turborepo](https://github.com/vercel/turborepo) | 28k | 单仓构建系统 | 远程缓存与任务图 |
| [biomejs/biome](https://github.com/biomejs/biome) | 20k | 一体化工具链 | Rust 高性能 |
| [vitest-dev/vitest](https://github.com/vitest-dev/vitest) | 15k | 现代测试框架 | 与 Vite 深度集成 |

## 使用建议

1. **先跑通再读码**：把项目跑起来，用一遍再回头看实现
2. **带着问题读**：聚焦「它怎么解决某个难点」，而不是逐行通读
3. **小步借鉴**：先抄一个模块的思路，再考虑整体架构
4. **注意许可**：商用前确认开源协议（MIT / Apache-2.0 / AGPL 差异很大）
