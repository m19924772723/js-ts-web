# 前端工程化与 CLI · 简介

> 构建工具、脚手架与开发者 CLI（Vite / tsup / Turborepo）

## 能做什么

- 脚手架一键生成项目
- 构建打包与产物优化
- 代码检查与格式化
- 单仓多包管理
- 发布 npm 包

## 适合的项目

- **内部脚手架**：统一项目模板
- **开源 CLI 工具**：开发者受众
- **构建插件**：扩展生态

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：Node 22/24、Vite、tsup / esbuild、Turborepo、Vitest
- 注意：面向自己的重复劳动做工具化，收益最直接

## 快速开始

```bash
mkdir my-cli && cd my-cli && npm init -y
npm i tsup typescript -D
npx tsup src/index.ts --format esm
```
