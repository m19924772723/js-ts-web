# 前端工程化与 CLI · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 构建 | Vite / tsup / esbuild | 快、配置少 |
| 单仓 | Turborepo / pnpm workspace | 多包协作 |
| 质量 | Biome / ESLint | 快且统一 |
| 测试 | Vitest | 与 Vite 同源 |
| 发布 | Changesets | 版本与变更日志 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **模块与打包**：ESM / CJS 与产物格式
- **CLI 交互**：参数解析与提示
- **单仓治理**：包依赖与缓存
- **发布流程**：版本、变更日志、CI

## 学习路径

1. 先写一个能跑的 Node CLI
2. 再抽成可发布的包
3. 最后接入 CI 自动发布
