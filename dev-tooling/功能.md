# 前端工程化与 CLI · 可实现的典型功能

> 以下为该子方向可落地的功能清单，可作为选题与需求池。

## 脚手架

- **模板生成**：一条命令建项目
- **交互式提问**：按需定制
- **依赖自动安装**：开箱可用

## 构建

- **多格式产物**：ESM / CJS / 类型
- **增量缓存**：构建更快
- **体积分析**：找出冗余

## 质量

- **lint / format**：统一风格
- **类型检查**：CI 卡点
- **提交规范**：Conventional Commits

## 发布

- **版本化**：语义化版本
- **变更日志**：自动生成
- **CI 发布**：打 tag 即发

---

> 每个功能都可独立成一个小项目，建议按「最小可用 → 好用 → 自动化」的顺序推进。
