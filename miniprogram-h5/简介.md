# 小程序 / H5 跨端 · 简介

> 微信小程序与移动 H5 页面开发

## 能做什么

- 小程序页面与组件
- 移动端 H5 活动页
- 一套代码多端运行
- 微信能力接入（登录 / 支付 / 分享）
- 云开发后端

## 适合的项目

- **工具类小程序**：轻量即用
- **活动 / 报名 H5**：分享传播
- **内容展示页**：移动端阅读

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：微信开发者工具（需装）、Taro / uni-app、Vant、Node 22/24
- 注意：真机调试与发布需微信开发者工具与小程序账号

## 快速开始

```bash
npx @tarojs/cli init my-app
cd my-app && npm install
npm run dev:weapp
```
