# 小程序 / H5 跨端 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 多端 | Taro / uni-app | 一次编写多端运行 |
| UI | Vant Weapp / Vant | 移动组件齐全 |
| 请求 | wx.request / axios | 统一封装 |
| 后端 | 微信云开发 | 免服务器 |
| 调试 | 微信开发者工具 | 真机预览 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **小程序生命周期**：页面与组件生命周期
- **跨端差异**：条件编译与平台特有 API
- **登录体系**：wx.login 换取会话
- **发布流程**：审核与版本管理

## 学习路径

1. 先跑通官方小程序示例
2. 再学一个跨端框架
3. 最后做一个带后端的小程序
