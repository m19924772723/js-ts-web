# Node 后端 API · 可实现的典型功能

> 以下为该子方向可落地的功能清单，可作为选题与需求池。

## 接口设计

- **REST 规范**：资源化 URL 与状态码
- **参数校验**：类型与范围校验
- **分页筛选**：列表通用能力

## 安全

- **鉴权**：JWT / 会话
- **权限**：角色与接口级控制
- **限流防刷**：保护接口

## 数据

- **ORM 读写**：模型与迁移
- **事务**：一致性保障
- **缓存**：Redis 加速

## 运维

- **结构化日志**：便于排查
- **健康检查**：探活接口
- **优雅退出**：不丢请求

---

> 每个功能都可独立成一个小项目，建议按「最小可用 → 好用 → 自动化」的顺序推进。
