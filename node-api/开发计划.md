# Node 后端 API · 开发计划

> 原则：**每个阶段都产出可运行、可验证的东西**，先小步跑通再逐步加深。

## 阶段一 · Hello API

- **目标**：能跑通
- **产出**：一个可访问的接口

- [ ] 起服务
- [ ] 写第一个路由
- [ ] 返回 JSON

## 阶段二 · 结构化

- **目标**：分层清晰
- **产出**：多接口的服务

- [ ] 路由分层
- [ ] 参数校验
- [ ] 统一响应与错误

## 阶段三 · 接数据

- **目标**：持久化
- **产出**：带数据库的服务

- [ ] 接入 ORM
- [ ] CRUD 接口
- [ ] 分页与筛选

## 阶段四 · 上线

- **目标**：可交付
- **产出**：有文档与鉴权的服务

- [ ] 鉴权与权限
- [ ] 接口文档
- [ ] 日志与部署

### 里程碑与验收

| 阶段 | 验收标准 |
|---|---|
| 阶段一 · Hello API | 一个可访问的接口 |
