# Node 后端 API · 简介

> 用 Express / Fastify / NestJS 构建 REST 或 GraphQL 后端

## 能做什么

- REST 接口与参数校验
- 鉴权与权限控制
- 文件上传与下载
- 数据库读写与事务
- 定时任务与 Webhook

## 适合的项目

- **独立后端服务**：供前端 / App 调用
- **BFF 聚合层**：聚合多个上游接口
- **Webhook 接收**：第三方回调处理

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：Node 22/24、Fastify / NestJS、Prisma、Zod、Swagger
- 注意：零依赖也可用原生 http 起步；生产建议加日志与优雅退出

## 快速开始

```bash
mkdir my-api && cd my-api && npm init -y
npm i fastify zod
node --watch server.mjs
```
