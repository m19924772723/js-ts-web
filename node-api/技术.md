# Node 后端 API · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 框架 | Fastify / NestJS | 性能与工程化俱佳 |
| 数据 | Prisma | 类型安全、迁移方便 |
| 校验 | Zod | 运行时校验 + 类型推断 |
| 文档 | Swagger / OpenAPI | 接口即文档 |
| 测试 | Vitest / Jest | 接口自动化测试 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **HTTP 基础**：方法、状态码、Header 语义
- **分层设计**：路由 → 服务 → 数据访问
- **鉴权**：JWT / Session 的取舍
- **错误处理**：统一响应格式与异常兜底

## 学习路径

1. 先用原生 http 写一个接口
2. 再引入框架与路由分层
3. 最后加数据库、鉴权与文档
