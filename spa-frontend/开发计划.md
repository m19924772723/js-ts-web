# 单页应用（SPA） · 开发计划

> 原则：**每个阶段都产出可运行、可验证的东西**，先小步跑通再逐步加深。

## 阶段一 · 跑通脚手架

- **目标**：能改能看
- **产出**：一个可访问的静态页面

- [ ] 初始化 Vite 项目
- [ ] 拆分组件与样式
- [ ] 本地预览通过

## 阶段二 · 交互与路由

- **目标**：多页可切换
- **产出**：带路由与状态的应用

- [ ] 接入路由
- [ ] 引入状态管理
- [ ] 表单与校验

## 阶段三 · 对接数据

- **目标**：真实数据驱动
- **产出**：连后端的完整应用

- [ ] 封装请求层
- [ ] 加载 / 错误态处理
- [ ] 登录态与权限

## 阶段四 · 体验与上线

- **目标**：可交付
- **产出**：部署上线的站点

- [ ] 暗色模式与响应式
- [ ] 性能与体积优化
- [ ] 静态托管部署

---

### 里程碑与验收

| 阶段 | 验收标准 |
|---|---|
| 阶段一 · 跑通脚手架 | 一个可访问的静态页面 |
| 阶段二 · 交互与路由 | 带路由与状态的应用 |
| 阶段三 · 对接数据 | 连后端的完整应用 |
| 阶段四 · 体验与上线 | 部署上线的站点 |

> 建议：每完成一个阶段就在本目录下建一个具体项目子目录，把成果固化下来。
