# 单页应用（SPA） · GitHub 精选项目

> 以下为该方向值得参考的开源项目，星标为 2026-10 前后近似值，请以仓库当前页面为准。
> 「可借鉴」一栏说明读源码或使用时最值得学习的地方。

| 项目 | 星标 | 亮点 | 可借鉴 |
|---|---|---|---|
| [facebook/react](https://github.com/facebook/react) | 251k | 最流行的 UI 库 | 组件化与生态设计 |
| [vuejs/core](https://github.com/vuejs/core) | 208k | 渐进式框架 | 上手曲线与文档组织 |
| [vitejs/vite](https://github.com/vitejs/vite) | 83k | 极快的前端构建 | 插件体系与开发体验 |
| [tailwindlabs/tailwindcss](https://github.com/tailwindlabs/tailwindcss) | 87k | 原子化 CSS | 设计令牌与主题系统 |
| [pmndrs/zustand](https://github.com/pmndrs/zustand) | 51k | 极简状态管理 | 小体积 API 设计 |

## 使用建议

1. **先跑通再读码**：把项目跑起来，用一遍再回头看实现
2. **带着问题读**：聚焦「它怎么解决某个难点」，而不是逐行通读
3. **小步借鉴**：先抄一个模块的思路，再考虑整体架构
4. **注意许可**：商用前确认开源协议（MIT / Apache-2.0 / AGPL 差异很大）
