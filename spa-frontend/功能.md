# 单页应用（SPA） · 可实现的典型功能

> 以下为该子方向可落地的功能清单，可作为选题与需求池。

## 页面与路由

- **多页路由**：页面切换与懒加载
- **嵌套路由**：布局复用
- **导航高亮 / 面包屑**：位置感知

## 数据与状态

- **接口请求**：统一封装 fetch / axios
- **状态共享**：登录态、主题、全局配置
- **表单校验**：必填 / 格式 / 联动

## 交互体验

- **暗色模式**：跟随系统或手动切换
- **骨架屏 / 加载态**：提升感知速度
- **响应式布局**：适配手机与桌面

## 工程化

- **环境变量**：区分开发 / 生产
- **代码分割**：按需加载
- **一键部署**：静态托管

---

> 每个功能都可独立成一个小项目，建议按「最小可用 → 好用 → 自动化」的顺序推进。
