# 单页应用（SPA） · 简介

> 用 React / Vue 构建交互密集型的浏览器单页应用

## 能做什么

- 组件化页面与路由
- 状态管理与表单校验
- 对接后端 REST / GraphQL
- 主题与暗色模式
- 打包成静态站点部署

## 适合的项目

- **个人博客 / 作品集**：内容展示 + 明暗主题
- **数据看板**：图表 + 卡片布局
- **工具类 Web 应用**：纯前端即可运行

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：Node 22/24、Vite、React 19 / Vue 3、Tailwind CSS、npm
- 注意：产物为静态文件，可双击 index.html 预览；上线需静态托管

## 快速开始

```bash
npm create vite@latest my-spa -- --template react-ts
cd my-spa && npm install
npm run dev   # 打开 http://localhost:5173
```
