# 单页应用（SPA） · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 框架 | React 19 / Vue 3 | 生态最大、组件最丰富 |
| 构建 | Vite | 秒级启动与热更新 |
| 状态 | Zustand / Pinia | 轻量、易调试 |
| 路由 | React Router / Vue Router | 标准方案 |
| 样式 | Tailwind CSS | 原子化、开发快 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **组件化思维**：把界面拆成可复用组件，props 向下、事件向上
- **状态管理**：局部状态优先，跨组件共享再引入状态库
- **路由与懒加载**：按路由分包，首屏只加载必要代码
- **构建与部署**：理解打包产物与静态托管的关系

## 学习路径

1. 先打通 HTML / CSS / JS 与 ES6 模块
2. 再学一个框架（React 或 Vue）的核心概念
3. 最后做一个完整应用并部署上线
