# 实时应用 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 通信 | Socket.IO / ws | 封装完善 / 轻量原语 |
| 推送 | SSE | 单向推送更省心 |
| 协作 | Yjs（CRDT） | 无冲突协同 |
| 广播 | Redis Pub/Sub | 多实例横向扩展 |
| 托管 | Supabase Realtime | 免自建 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **连接生命周期**：握手、心跳、断线与重连
- **消息可靠**：确认、重试、去重
- **状态同步**：操作变换(OT) vs 无冲突复制(CRDT)
- **扩展**：多实例下的消息广播

## 学习路径

1. 先用 ws 写一个回声服务
2. 再做房间与广播
3. 最后接入 CRDT 做协同
