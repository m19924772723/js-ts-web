# 实时应用 · 简介

> WebSocket / SSE 驱动的实时通信与协作应用

## 能做什么

- 即时聊天与消息推送
- 实时通知与在线状态
- 多人协同编辑
- 实时数据看板
- 直播弹幕

## 适合的项目

- **聊天 / 在线客服**：消息实时可达
- **协同白板 / 文档**：多人同时编辑
- **实时看板**：数据秒级刷新

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：Node 22/24、Socket.IO / ws、Redis（已运行 :6379）、Yjs
- 注意：本机 Redis 可做多实例广播；注意断线重连与状态同步

## 快速开始

```bash
mkdir my-rt && cd my-rt && npm init -y
npm i ws
node server.mjs
```
