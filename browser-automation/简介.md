# 浏览器自动化与采集 · 简介

> 用 Playwright / Puppeteer 做网页自动化与数据采集

## 能做什么

- 静态与动态页面抓取
- 表单自动填写与提交
- 整页截图与导出 PDF
- 端到端自动化测试
- 定时采集与监控

## 适合的项目

- **数据采集**：榜单 / 价格 / 内容
- **自动化办公**：重复网页操作
- **站点监控**：变化检测与告警

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：Playwright 1.63（已装 2 套浏览器）、Node 22/24、Cheerio
- 注意：注意站点条款与请求频率；本机已装 Playwright 浏览器可直接用

## 快速开始

```bash
npm i playwright
npx playwright install chromium
node crawl.mjs
```
