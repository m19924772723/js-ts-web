# 浏览器自动化与采集 · 可实现的典型功能

> 以下为该子方向可落地的功能清单，可作为选题与需求池。

## 采集

- **列表抓取**：分页遍历
- **详情抓取**：进入详情页
- **接口直取**：直接调 API

## 自动化

- **自动填表**：批量提交
- **截图 / PDF**：存档导出
- **文件下载**：自动保存

## 稳健性

- **重试退避**：失败自愈
- **登录态复用**：免重复登录
- **去重**：避免重复数据

## 调度

- **定时执行**：每日跑
- **变更监测**：有变化才通知
- **日志留痕**：可回溯

---

> 每个功能都可独立成一个小项目，建议按「最小可用 → 好用 → 自动化」的顺序推进。
