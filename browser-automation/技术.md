# 浏览器自动化与采集 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 浏览器 | Playwright | 跨浏览器、API 现代 |
| 解析 | Cheerio / lxml | 结构化提取 |
| 调度 | Windows 计划任务 | 定时执行 |
| 存储 | SQLite / JSON | 落地与去重 |
| 稳健 | 代理 / 指纹 | 提升成功率 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **定位与等待**：选择器、显式等待
- **登录态**：复用 Cookie / storageState
- **反爬基础**：UA、频率、指纹
- **数据落库**：去重与增量

## 学习路径

1. 先用 Playwright 打开页面取文本
2. 再做分页与增量
3. 最后加定时与告警
