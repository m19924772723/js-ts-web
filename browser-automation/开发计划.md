# 浏览器自动化与采集 · 开发计划

> 原则：**每个阶段都产出可运行、可验证的东西**，先小步跑通再逐步加深。

- **目标**：能取数
- **产出**：抓到首个字段

- [ ] 启动浏览器

## 阶段二 · 批量抓取

- **目标**：成规模

- [ ] 分页遍历

- **目标**：可持续
- **产出**：增量入库的数据

- [ ] SQLite 落库
